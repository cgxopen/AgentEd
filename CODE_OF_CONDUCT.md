# Code of Conduct

AgentEd adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every space of this project: issues, pull requests, reviews and discussions.

## In short

- Be respectful and constructive, including when you disagree.
- Criticise the work, not the person.
- No harassment, insults or personal attacks, and no sexualised language or imagery.
- Do not publish the private information of anyone without their permission.

## Reporting

If someone breaks this code, report it privately to the maintainer at **CONTACT-TO-BE-DECIDED**. Every report is read, and the name of the person reporting is kept confidential.

AgentEd has one maintainer. If a report concerns the maintainer, use the **Report content** option GitHub offers on every comment, issue and pull request.

## Enforcement

The maintainer may edit, hide or remove comments, commits, code and issues that break this code, and may block anyone who does so from the project, for a time or for good. The steps follow the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant: a correction, a warning, a temporary ban, a permanent ban.
